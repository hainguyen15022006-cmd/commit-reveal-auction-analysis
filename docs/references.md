## Cited sources

**[1]** NIST. *Secure Hash Standard (SHS)*. FIPS PUB 180-4, August 2015.
https://doi.org/10.6028/NIST.FIPS.180-4

- Cited location: Sec. 1, p. 3 (printed page 3; PDF page 8). Verified.
- Supports: definition of SHA-256 and its 256-bit digest; a changed message yields
  a different digest with very high probability (Background).

**[2]** MIT 6.5610. *Recitation 6: Hash functions*. Spring 2023, March 17, 2023.
https://65610.csail.mit.edu/2023/rec/rec6.pdf

- Cited location: Sec. 1, p. 1. Verified.
- Supports: collision resistance and the random oracle model; application 5 states
  that commitments generally require collision resistance for computational binding
  and the ROM for hiding (Background, Security analysis).
- Optional: p. 3, part (d), a hiding commitment must be randomized (B0 discussion).
